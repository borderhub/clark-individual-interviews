# 公開・共有ゲート（RELEASE GATE）

本リポジトリの成果物を、リポジトリ外へ **共有** または **公開** する前に通す判定手順。

> [!IMPORTANT]
> **GitHub Pages、公開ダッシュボード、公開用データは作成しない。**
> 本ゲートは「不特定多数への公開」を想定していない。
> 想定するのは、**承認された相手への、非再識別・集計済み結果の限定共有** のみ。

## 前提条件（すべて満たさない限り、ゲートに進まない）

- [ ] 対象データの取扱区分が **`pending` ではない**
- [ ] 人間の責任者が、動画の所有・利用権限を確認済み
- [ ] 人間の責任者が、文字起こし・分析への同意を確認済み
- [ ] 学校・保護者を含む必要な手続きが完了していることを、人間の責任者が確認済み
- [ ] （アンケート回答を含む場合）面談動画の同意とは **別に**、
      アンケート回答の分析・共有の可否が確認済み

いずれか1つでも未達なら、**共有しない**。

## 除外チェック（1つでも該当すれば不可）

成果物に、次のいずれかが含まれていないか確認する。

- [ ] 生動画
- [ ] 音声
- [ ] 文字起こし（全文・部分・逐語引用を問わない）
- [ ] 事前アンケート回答
- [ ] 個別回答
- [ ] 時刻・タイムスタンプ
- [ ] 話者ID
- [ ] 個人別集計
- [ ] 氏名・呼ばれたい名前・所属・学年など直接識別子
- [ ] 匿名IDと実名の対応表、またはそれを復元しうる情報

## 再識別リスクチェック

- [ ] 小さすぎるセル（該当人数が少ない集計）を含んでいないか
- [ ] 複数の属性の組み合わせで個人が特定されないか
- [ ] 固有のエピソード記述により個人が特定されないか
      （エピソードは抽象化するか、含めない）
- [ ] 部内の人間なら誰のことか分かる表現になっていないか

## 解釈チェック

- [ ] 「個人面談＝本音、グループ＝建前」という解釈をしていないか
      → **面談形式の違い** として記述すること
- [ ] `pending` のデータを根拠・引用に使っていないか
- [ ] 集計結果が、元の発言者に不利益をもたらす形で提示されていないか

## 承認記録

上記をすべて満たした場合のみ、`release_register`（→ `private/registers/`）に
次を記録したうえで共有する。

- 共有物の識別子と内容
- 共有先と共有範囲
- 各チェック項目の確認者（人間）と確認日
- 承認者（人間の責任者）と承認日

**承認記録のない共有は行わない。**
自動処理・エージェントは、本ゲートの判定を代行・省略してはならない。

## グループセッションとの比較

- 比較は **将来、別のprivate環境** で行う。
- 扱えるのは **双方の承認済み・非再識別・集計済み結果だけ**。
- 本リポジトリの生データを `clark-group_session` へ移動・複製・参照しない。
