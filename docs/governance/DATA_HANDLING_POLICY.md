# データ取扱方針（DATA HANDLING POLICY）

クラーク高校演劇部・個人面談データの取扱いに関する方針。
本リポジトリで作業する全員（人間・エージェントを含む）に適用する。

## 1. 取扱区分

| 区分 | 意味 | 許可される操作 |
| --- | --- | --- |
| `pending` | **初期区分。すべての個人面談データはここから始まる。** | 受け入れ・ローカル保管・台帳への記録のみ |
| `approved_internal` | 人間の責任者が内部分析を承認した状態 | 内部での分析・非再識別化作業 |
| `approved_aggregate` | 非再識別・集計済み結果の共有を承認した状態 | 承認された範囲での共有 |
| `withdrawn` | 同意撤回・利用不可 | 削除・不使用 |

> [!IMPORTANT]
> **個人面談の初期取扱区分はすべて `pending` とする。**
> `pending` のデータは **分析・引用・外部共有・公開をしない。**

区分を進められるのは **人間の責任者の確認後** のみ。自動処理は区分を昇格させない。

## 2. 人間の責任者が確認すること

次の各項目は、エージェントや自動処理が判断・推定・代行してはならない。

- 動画の **所有権・利用権限**
- **文字起こし** への同意
- **分析** への同意
- **学校・保護者を含む必要な手続き**（本人同意のみでは足りない場合がある）
- 事前アンケート回答を分析対象に含めてよいか
  （**面談動画の同意とは別の確認事項**。確認が取れるまで保留）

確認結果は `consent_scope_register`（→ `private/registers/`）に記録する。

## 3. 保管場所とGit追跡

| 種別 | 保管場所 | Git |
| --- | --- | --- |
| 事前アンケート原本（CSV） | `private/intake/` | 追跡しない |
| 同意関連の記録 | `private/consent/` | 追跡しない |
| 実データ入り台帳 | `private/registers/` | 追跡しない |
| 文字起こし | `private/transcripts/` | 追跡しない |
| 非再識別化後データ | `private/anonymized/` | 追跡しない |
| コーディング作業 | `private/coding/` | 追跡しない |
| 人手レビュー記録 | `private/review/` | 追跡しない |
| 動画・音声原本 | `sources/` | 追跡しない |
| 中間生成物 | `derived/` | 追跡しない |
| 出力候補 | `exports/` | 追跡しない |
| 方針・手順・列定義テンプレート | `docs/` | **追跡する**（実データを含まないこと） |
| スクリプト | `scripts/` | **追跡する**（実データを含まないこと） |

**氏名等と匿名IDの対応表（リンケージ表）は、Gitに置かない。別保管とする。**
`private/` 配下であっても、リンケージ表は他のデータと同じ場所に置かず、
アクセス範囲を分けて管理する。

## 4. 事前アンケートの特別扱い

事前アンケートには、氏名、呼ばれたい名前、悩み、検索履歴・メモ・SNSに関わる内容、
感情が強く動いた出来事、面談で話したいことが含まれる。
**要配慮性の高い生データ** として、次を厳守する。

- CSVの内容を **表示・要約・分析しない**
- Gitに **追加・commitしない**
- `private/intake/` に **ローカル保管** する
- **質問文だけ** を、実回答と分離して手順書に記録してよい
- 分析対象に含めるかは、**別途確認まで保留**

## 5. 話者の扱い

- 個人面談では **話者分離（diarization）を前提にしない。**
- 面談者と生徒の区別が必要になった場合も、**まず質問ログ（question register）で処理する。**
  質問の発話区間と回答区間の対応で足りる場合、話者推定は行わない。
- 話者IDは、いかなる共有・公開用成果物にも含めない。

## 6. 成果物に含めてはならないもの

共有用・公開用のいかなる成果物にも、次を含めない。

- 生動画、音声
- 文字起こし（全文・部分・逐語引用を問わない）
- 事前アンケート回答
- 個別回答
- 時刻・タイムスタンプ
- 話者ID
- 個人別集計

## 7. 他リポジトリ・他プロジェクトとの関係

- 本リポジトリは既存の `clark-group_session` とは **完全に別のprivateリポジトリ** である。
- 個人面談の生データを既存リポジトリへ **移動・複製・参照してはならない。**
- 将来の比較は **別のprivate環境** で、**双方の承認済み・非再識別・集計済み結果だけ** を扱う。
- 比較にあたり「個人面談＝本音、グループ＝建前」という解釈をしない。
  **面談形式の違い** として比較する。

## 8. 公開に関する前提

- **GitHub Pages、公開ダッシュボード、公開用データは作成しない。**
- 共有・公開の可否判定は [RELEASE_GATE.md](RELEASE_GATE.md) に従う。

## 9. 現時点の実行禁止事項

文字起こし、話者推定、テーマ分析、公開用出力、動画ダウンロードは **未実施** であり、
人間の責任者の承認があるまで **実行しない**。
